# Australian-Airline-Performance-Analysis
Australian Airline Performance Analysis (2023–2026)  A data analytics project using MySQL and Power BI to analyse Australian domestic airline punctuality, cancellations, route performance and operational trends.

## SQL Skills Demonstrated

- Data cleaning using REPLACE() and TRY_CAST()
- Data type conversion and validation
- Aggregate analysis using GROUP BY
- Airline performance ranking
- Route and airport performance analysis
- Time-series trend analysis (2023–2026)
